# cronboard-api

Core types, storage interface and in-memory storage for CronBoard.

Part of [CronBoard](https://github.com/Zaki-goumri/cron-board), a dashboard for `@nestjs/schedule` cron jobs.

Most apps only need `cronboard-nestjs`:

```bash
pnpm add cronboard-nestjs @nestjs/schedule
```

See the [main README](https://github.com/Zaki-goumri/cron-board#readme) for setup.
